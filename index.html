CZN Research

CZN Researchは、YouTubeチャンネル「夜更けのカオス研究室」の運営者が、チャンネル分析とゲーム関連資料の整理に使用する個人用ツール群です。Googleの同意画面では「CZN Research」、デスクトップ接続設定では「CZN Capture」と表示される場合があります。ツールは一般向けに提供していません。

YouTube配信分析

運営者本人のチャンネルの再生回数、視聴時間、登録者数などを、YouTube Data API v3とYouTube Analytics APIで読み取り、配信内容の分析に使います。

Discord資料取得アプリ（CZN Capture）

運営者が閲覧できるDiscordの画面を手動で指定して撮影し、PC内でOCRと資料整理を行います。Google Drive連携を有効にすると、画像・OCR原文・整理候補などをまとめたZIPを、運営者のDriveの専用フォルダーへ送信します。Google接続でDiscordアカウントへのアクセス権限を取得することはありません。

Driveにはdrive.file権限を使用し、このアプリが作成したファイル、または利用者がアプリに許可したファイルへのアクセスに限定します。Drive全体を読み取る権限は要求しません。送信したZIPの公開共有設定は行いません。

Drive上の資料は、運営者が別途接続・操作する資料整理サービスで利用する場合があります。取得アプリ自体がMuseを起動したり、Notionを自動更新したりする機能はありません。

詳しいデータの扱いはプライバシーポリシー、利用条件は利用規約をご覧ください。
