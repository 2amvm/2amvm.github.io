プライバシーポリシー

本方針は、個人用ツール群「CZN Research」（YouTube配信分析およびDiscord資料取得アプリ「CZN Capture」）に適用します。

取得・利用する情報と目的

YouTube配信分析は、運営者本人のチャンネル統計をYouTube Data API v3およびYouTube Analytics APIから読み取り専用で取得し、チャンネル分析に使用します。使用権限はyoutube.readonlyおよびyt-analytics.readonlyです。

CZN Captureは、運営者が選択した画面画像、OCR原文、会話の話者名・時刻など画像に含まれる情報、および整理候補をPC内に保存します。Drive連携時は、これらを含むZIPを運営者のDriveへ送信し、資料保管と運営者による資料整理に使用します。Drive APIから接続アカウントのメールアドレス、専用フォルダーとアプリ管理ファイルの識別情報・メタデータを取得し、接続先の確認と送信・削除の管理に使用します。Driveの権限はhttps://www.googleapis.com/auth/drive.fileです。

保管と保護

認証情報は運営者の管理環境で保管します。CZN CaptureのOAuthトークンはWindowsの利用者に紐づく暗号化を用いてPC内に保存します。送信対象の資料はローカル保存先と運営者のDriveに保管します。本案内サイトにはGoogleの認証情報や取得資料を掲載しません。

共有と外部サービス

Google APIから取得した情報を販売したり、広告目的で利用したりしません。取得アプリは送信資料を一般公開に変更しません。運営者がDriveに接続したMuse等の別サービスで資料を整理する場合は、そのサービスへの接続と運営者の操作・指示に基づいて資料が扱われます。各サービスの利用条件とプライバシーポリシーも適用されます。取得アプリから別サービスへの資料整理・反映の自動実行は行いません。

保持と削除

PC内の原画像・OCR原文・ZIPは運営者が管理・削除するまで保持します。Drive上のアプリ送信ZIPは、整理結果の反映、根拠保持、追加資料待ちがないこと、ローカルから再送可能なことを運営者側で確認した受領票がある場合に限り、確認から7日後以降のアプリ稼働時に削除対象となります。接続認証の7日期限とは別の仕組みです。条件未成立の資料は期限だけでは削除しません。運営者はDrive上のファイルを手動でも削除できます。

許可の取り消し

Googleアカウントの接続設定からアクセス許可を取り消せます。取り消しは保存済みの資料を自動削除するものではありません。削除に関する問い合わせは下記連絡先で受け付けます。

GoogleおよびYouTubeの条件

Google APIから受け取る情報の使用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。YouTube機能にはYouTube利用規約とGoogleプライバシーポリシーが適用されます。
