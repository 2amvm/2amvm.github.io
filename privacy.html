プライバシーポリシー

「YouTube配信分析」は、運営者本人が自分のYouTubeチャンネルのアナリティクス（再生回数、視聴時間、登録者数の推移など）を読み取り専用で取得し、分析するためだけの個人用ツールです。

取得する情報：YouTube Data API v3 および YouTube Analytics API を通じて、運営者本人のチャンネルの統計情報のみを取得します。権限は読み取り専用（youtube.readonly、yt-analytics.readonly）です。

利用目的：取得した情報は運営者本人のチャンネル分析のためだけに使います。第三者への販売、提供、公開はしません。

保管：取得に使う認証情報は運営者の管理環境内にのみ保管します。

許可の取り消し：許可は Google アカウントの「サードパーティ製のアプリとサービス」設定からいつでも取り消せます。

本ツールは YouTube API Services を利用しており、YouTube の利用規約および Google プライバシーポリシーもあわせて適用されます。

問い合わせ先：OAuth 同意画面に表示されているサポートメールアドレスまで。
